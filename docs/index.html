scanip

Zeigt jedes Gerät im Netzwerk – mit IP-Adresse, offenen Ports, MAC-Adresse, vermuteter Gerätekategorie und Gerätename.

Windows · macOS · Linux Ohne Administratorrechte Keine Abhängigkeiten MIT-Lizenz
Download für macOS .app · Apple Silicon & Intel Download für Windows .exe · einzelne Datei Quellcode auf GitHub

Beide Pakete bringen alles Nötige mit – es muss kein Python installiert werden. Auch direkt aus dem Quellcode nutzbar.

Funktionen

Drei Bedienwege

Browser-Oberfläche mit Live-Fortschritt, klassisches Fenster und Kommandozeile – alle mit demselben Funktionsumfang.

Namen aus fünf Quellen

Reverse-DNS, mDNS/Bonjour, NetBIOS, SNMP und SSDP/UPnP werden parallel abgefragt – selbst implementiert, ohne Fremdbibliotheken.

Begründete Kategorien

Offene Ports, MAC-Hersteller, Namensmuster und angebotene Dienste ergeben eine Punktzahl. Jede Einordnung ist nachvollziehbar begründet.

Ohne Sonderrechte

TCP-Connect-Scan statt Rohsockets: keine Administrator- oder Root-Rechte, keine Treiberinstallation.

Eigene Notizen

Zu jedem Gerät eine Anmerkung hinterlegen – gespeichert über die MAC-Adresse und damit auch dann erhalten, wenn sich die IP ändert.

Export

HTML-Report zum Sortieren und Filtern, CSV für Excel und JSON zur Weiterverarbeitung.

Nur Standardbibliothek

Keine externen Pakete, keine Telemetrie, keine Netzwerkverbindung nach außen. Rund 5.300 Zeilen Python mit 102 Tests.

Ohne Download starten

Wer Python hat, braucht die Pakete nicht.

git clone https://github.com/fmatsch/scanip.git
cd scanip
python3 -m scanip --web        # Browser-Oberfläche
python3 -m scanip              # Kommandozeile, eigenes Netz
python3 -m scanip 192.168.1.0/24 --why -o bericht.html

Vorausgesetzt wird Python 3.8 oder neuer. Weitere Optionen stehen in der Dokumentation.

Vor dem ersten Start

macOS

Die App ist nicht signiert. Beim ersten Start deshalb Rechtsklick → Öffnen wählen und den Hinweis bestätigen; danach startet sie normal per Doppelklick.

Windows

SmartScreen meldet einen unbekannten Herausgeber. Über „Weitere Informationen“ → „Trotzdem ausführen“ lässt sich die Datei starten.

Rechtlicher Hinweis: Portscans nur in Netzen durchführen, für die eine Berechtigung vorliegt – also im eigenen Netz oder mit ausdrücklicher Erlaubnis des Betreibers. In fremden Netzen kann ein Scan unzulässig sein.
